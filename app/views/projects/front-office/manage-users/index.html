Lets an admin user see everyone who has access to their plans, and the access level they have on each plan (admin or basic). Admins can add a user (name, email, plans and access level per plan), change a user's details and access, and remove a user. Admins cannot remove themselves.

  • Add: name → email → plans → access per plan → check answers → success banner
  • Change: user list → check answers page with change links → save → success banner
  • Remove access to one plan: user list → Change → Remove access (on a plan row) → confirmation → success banner. If it's their only plan, this goes to remove user instead.
  • Remove: user list → confirmation → success banner
